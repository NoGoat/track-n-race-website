Privacy Policy

Last Updated: October 22, 2026

1. Introduction

Track N Race ("Track N Race," the "Application," "we," "us," or "our") is an open-source, local-first telemetry dashboard and session recording application designed for use with racing simulation software and compatible devices.

This Privacy Policy describes how the Application accesses, processes, stores, and handles information when you use it.

Track N Race is designed to operate without a backend server or cloud-based data processing infrastructure. The Application does not operate a service that collects user telemetry, account information, or other personal information from the Application. Communications required for its functionality take place between compatible devices on the user's local network.

This Privacy Policy applies to the Track N Race mobile application. The hosting and operation of the Track N Race website are separate from the Application and are not governed by this document.

By using the Application, you acknowledge the practices described in this Privacy Policy.

2. Information We Collect and Process

Track N Race does not operate a backend collection system and does not intentionally collect or transmit users' personal information to the developer.

The Application may process the following information locally or exchange it with compatible devices on your local network to provide its functionality.

2.1 Racing Telemetry

The Application receives and processes racing simulation telemetry, which may include:

  • Vehicle speed, gear, throttle, and brake inputs.
  • Tyre temperatures and other vehicle parameters.
  • Lap times, session information, and timing data.
  • Vehicle position and other simulation-provided information.

This information is processed to display dashboard instruments, graphs, timing information, and other supported features. Where applicable, telemetry is exchanged between compatible devices on the user's local network.

2.2 Device Identification Information

During device pairing, the Application may transmit a randomly generated device identifier and the device's model name to the compatible Track N Race desktop application over the local network. This allows the desktop application to identify and display the device for pairing and connection management.

This information is not transmitted to a Track N Race-operated backend or external analytics service.

2.3 Locally Stored Information

Depending on the features you use, the Application may store information on your device, including:

  • Application preferences and configuration.
  • Desktop pairing information and reconnection credentials.
  • Optional telemetry session recordings.
  • Other data necessary for the Application to function.

This information remains under your control, subject to the storage permissions, Android system behavior, and any actions you take to export or share it.

3. Device Permissions

The Application requests permissions necessary to support its features. Permissions may vary by Android version and Application release.

3.1 Camera Access

Permission android.permission.CAMERA
Purpose Camera access is used to scan a QR code displayed by the Track N Race desktop application for device pairing.
Data handling Camera access is used for real-time QR code recognition. Camera frames are processed on the device and are not intended to be saved as photographs or video recordings or transmitted over a network by the Application.

You may revoke camera permission through Android settings. QR-based pairing will not be available while camera access is denied, although other functionality may remain available.

3.2 Network and Wi-Fi Access

Permissions android.permission.INTERNET, android.permission.ACCESS_NETWORK_STATE, android.permission.ACCESS_WIFI_STATE, and any applicable local-network permissions supported by the targeted Android version.
Purpose Network access supports receiving racing simulation telemetry over the local network (including UDP packets on the configured port, which defaults to 20777 where applicable), discovering compatible Track N Race desktop applications through mDNS/DNS-SD, and exchanging telemetry, pairing information, and control messages with a paired desktop application over local WebSocket connections.
Data handling The Application is designed to exchange operational data between compatible devices on the user's local network. It does not intentionally transmit telemetry or pairing information to an external Track N Race backend, cloud service, advertising network, or analytics service.

The Application's network functionality depends on the configuration of the user's network and compatible devices.

3.3 Wake Lock

Permission android.permission.WAKE_LOCK
Purpose The Application may use a wake lock or an appropriate Wi-Fi performance lock, where supported, to reduce power-saving interruptions that could affect network reliability during an active session.

This permission is used to support the Application's operation and is not used to collect personal information.

4. Local Storage and Session Recordings

The Application may offer an optional session recording feature, which is disabled by default where configured as described in the Application.

When enabled, telemetry data may be saved in .tnrd files in an application-accessible Documents directory or in a location selected by the user through the Android document picker.

Session recordings are stored locally unless you choose to move, export, or share them. The developer does not receive these recordings through a Track N Race-operated server.

You are responsible for managing exported recordings and any copies stored in other locations or shared with other parties.

5. Security and Pairing Credentials

The Application may store credentials used to reconnect to a previously paired desktop application.

Subject to verification of the implementation, these credentials are encrypted at rest using AES-GCM with a 256-bit key managed through the Android Keystore system. The Application is designed to prevent these credentials from being included in ordinary system backups.

Security depends on the device, Android version, operating system integrity, and the actual implementation of the Application. No method of local storage or electronic communication can be guaranteed to be completely secure under all circumstances.

You should keep your device and operating system up to date and protect access to your device.

6. Third-Party Services, Analytics, and Advertising

The Track N Race mobile Application does not intentionally integrate third-party advertising networks, analytics SDKs, behavioral tracking services, or crash-reporting SDKs.

The Application does not operate or rely on a Track N Race backend server for collecting telemetry or user information.

The Track N Race website is hosted separately from the Application. Website hosting, server logs, website analytics, and other website-related processing are subject to the applicable practices and policies of the website hosting provider and any website services that are enabled.

This Privacy Policy does not claim to govern information collected independently by third-party websites, operating systems, network providers, or other services outside the Application's control.

7. Disclosure and Sharing of Information

The developer does not sell, rent, or disclose personal information to third parties through a Track N Race-operated backend, because the Application is designed without such a backend collection service.

Information may be exchanged between your own compatible devices as necessary for the Application's functionality. You may also choose to export, transfer, or share recordings or other locally stored files yourself.

Information that you voluntarily disclose or transfer outside the Application may become subject to the privacy practices of the recipient or service involved.

8. Data Retention and Deletion

The Application does not maintain a developer-operated server-side repository of users' telemetry, pairing information, or session recordings.

Locally stored information may be deleted or managed as follows:

Pairings
Use the Application's "Forget Desktop" feature, where available, to remove the associated pairing.
Session recordings
Delete .tnrd files through the Application, a file manager, or the storage location in which they were saved.
Application settings and local data
Clear the Application's data through Android settings or uninstall the Application, subject to Android's storage behavior and any files exported to other locations.

Uninstalling the Application or clearing its data is not guaranteed to delete files that you previously exported or saved outside the Application's managed storage.

9. Children's Privacy

Track N Race does not intentionally collect personal information from children through a developer-operated backend.

The Application is not designed to solicit personal information from children. If you believe personal information has been inadvertently disclosed to the developer in connection with the Application, you may contact us using the details in Section 12.

10. Your Privacy Choices

You can exercise control over the information processed by the Application by:

  • Revoking device permissions through Android settings.
  • Choosing whether to enable optional session recording.
  • Removing paired desktop devices.
  • Deleting locally stored recordings and Application data.
  • Choosing whether to export or share locally stored files.

The availability of specific controls may vary by Application version and Android version.

11. Changes to This Privacy Policy

This Privacy Policy may be updated to reflect changes to the Application, its functionality, applicable legal requirements, or its data-handling practices.

When changes are made, the revised policy will be published with an updated "Last Updated" date and documented in the project repository where appropriate.

Your continued use of the Application after an updated policy is published constitutes use of the Application subject to the revised policy, to the extent permitted by applicable law.
